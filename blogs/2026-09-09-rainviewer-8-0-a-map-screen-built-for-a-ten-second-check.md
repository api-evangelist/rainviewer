RainViewer 8.0 clears the map screen, on iOS and Android. The name of the active layer is written on the map, the player shows one time, playback options now live behind one button, and a new fullscreen mode gives the whole screen to the radar. iOS 26 wraps this in Apple’s Liquid Glass; Android gets it in Material 3.
